# bcc-aman
BCC Аман — семейная защита переводов от мошенников 

Проект для ITU Hackathon-2026, кейс Банка ЦентрКредит.

Когда пожилой клиент делает необычный перевод, BCC Аман ставит его на паузу, а доверенный человек (например, внучка) получает понятное объяснение от ИИ и может позвонить, остановить или разрешить перевод. Счётчик 24 часа ловит переводы частями и получателей-дропов, а банк после остановки видит сеть связанных счетов и готовое досье.

## Прототип
- index.html — интерактивный MVP: приложение клиента, приложение доверенного лица, пульт банка
- Казахский и русский язык, пошаговое демо по Enter
- Открыть: скачайте index.html и откройте в браузере

## Технологии
Сейчас: HTML, CSS, JavaScript, Web Speech API.
В разработке: Python, FastAPI, SQLite, scikit-learn (Isolation Forest), LightGBM, networkx, XGBoost, LLM + шаблоны Jinja2.
